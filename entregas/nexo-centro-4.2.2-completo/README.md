# Nexo Centro 4.2.2 · Instalación completa desde cero

**Validado en Windows: 598 comprobaciones correctas, 0 fallos.** Además, 25 comprobaciones locales del empaquetado.

Incluye servidor autocontenido, cliente 4.2.2 con modelo A, asistentes 1.2.8, manual PDF para principiantes y fuentes. Sin datos ni identidades de otros centros.

1. Descarga y extrae TODO el ZIP.
2. Lee [MANUAL-INSTALACION.pdf](MANUAL-INSTALACION.pdf).
3. En el ordenador central, ejecuta `Instalar-NexoCentro-Servidor.exe` y deja «Agenda actual» vacía.
4. Usa los instaladores de Jefatura, Dirección y Secretaría generados por ESE servidor. En el ordenador central instala también el de Jefatura.
5. Revisa la red y adapta el calendario oficial del centro; comprueba que los cambios se propagan entre los puestos.

[Resultados de Windows](https://github.com/vygos7/historia/actions/runs/42382486049). Incluye instalación con agenda vacía, primera actividad, servicio real, cortafuegos con perfil Público, tres puestos, sincronización, actualización y recuperación.
