# Nexo Centro 4.0.4 — interfaz r1

**Candidato pendiente de las ocho baterías Windows.** No sustituir todavía la instalación del colegio.

Nueva marca Nexo Centro, calendario despejado y agenda diaria. Se conservan exactamente 18 archivos de lógica y servidor, las bibliotecas externas y el payload del servidor validado. Las rutas, configuración, identidad de puestos, servicio y protocolos mantienen sus identificadores para compatibilidad. El ZIP incluye instaladores cliente y servidor, requisitos, archivos modificados y evidencias.

La actualización visual de un puesto existente se hace con `Instalar-NexoCentro-Cliente.exe`; no requiere reinstalar el servidor.
