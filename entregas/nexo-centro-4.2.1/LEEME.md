# Nexo Centro 4.2.1

Retirada del proceso de formularios Google: sin sus botones, menús, pantallas, autorización, bibliotecas ni recogida de respuestas. Se conservan las tareas, la evaluación manual de las salidas, las memorias, los informes, las copias de seguridad y el trabajo compartido.

Extrae NexoCentro-4.2.1.zip y abre ABRIR-DEMO.cmd para probar la interfaz con datos ficticios separados. Para actualizar el cliente existente, utiliza Instalar-NexoCentro-Cliente.exe manteniendo su .exe.config junto a él. No es necesario actualizar el servidor.

La entrega incluye el código fuente y el manual. No incluye un instalador de servidor ni datos reales del colegio.
